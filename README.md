# Waste-classification-project

#### Problem Statement :- 
Increasing amount of e-waste at a global level requires smarter waste management techniques. We need an automatic waste classification system to segregate the different types of wastes. This project aims to fine-tune some pretrained deep-learning models on a Laptop components dataset [(download)](https://prod-dcd-datasets-cache-zipfiles.s3.eu-west-1.amazonaws.com/pwctygncrj-4.zip)
